# Hồ sơ kiểm chứng

Lưu cách chạy, kết quả đã đo và giới hạn của mỗi bản thử nghiệm. Không đưa inventory
máy cá nhân, đường dẫn người dùng, log có bí mật hoặc runtime output vào Git.

Core v1 được kiểm chứng theo [đặc tả](../specs/core-v1.md). Xem
[kết quả Windows](core-v1-windows.md), số đo thực tế và phần còn chưa kiểm chứng.

- [Windows Setup 0.1.1](windows-setup-0.1.1.md): wizard native, tests và giới hạn phát hành.
- [Windows uninstall 0.1.2](windows-uninstall-0.1.2.md): đăng ký Windows, dữ liệu giữ/xóa và phạm vi test cô lập.
- [Dữ liệu và Windows 0.1.3](core-data-0.1.3.md): backup/migration, rollback, cache, Sandbox và sửa hash payload.
- [UI thư viện và SDK v1](plugin-ui-sdk-v1.md): source chưa phát hành, UI prototype, contract/client tests và native regression.
- [Windows setup design QA](windows-setup-design-qa.md): lưu lại báo cáo hình ảnh bộ cài trước khi root design QA chuyển sang thư viện.


- [Đồng hồ v1](clock-v1.md): nghiệp vụ, persistence/backup, giao diện và IPC native của source chưa phát hành.

- [Updater GitHub 0.1.4](updates-0.1.4.md): gói có chữ ký, UI, source update và Sandbox.
