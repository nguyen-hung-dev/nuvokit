# NuvoKit 0.1.4 — Windows preview

- Thêm Tổng quan, thư viện plugin với bộ lọc và chuyển bố cục lưới/chi tiết.
- Đồng hồ tích hợp: tập trung, đếm ngược, bấm giờ; ba bố cục, theme riêng,
  lưu phiên/lịch sử trên thiết bị và sao lưu dữ liệu.
- Cập nhật từ GitHub trong Cài đặt: chọn kênh, kiểm tra, tải có tiến trình,
  xác minh chữ ký và phiên bản, xác nhận cài khi sẵn sàng.
- Giữ dữ liệu khi nâng cấp, tạo bản phục hồi trước khi thay app; chặn cài khi
  còn tác vụ dữ liệu hoặc phiên Đồng hồ đang hoạt động.
- Dev cập nhật source bằng Git với kiểm tra thay đổi local và fast-forward.

Người dùng 0.1.3 trở về trước cần cài bộ cài mới một lần để nhận updater.
Bộ cài Windows chưa có chứng chỉ Authenticode; chữ ký gói cập nhật Tauri là
cơ chế riêng. Windows 11 x64; các plugin ngoài Đồng hồ vẫn là bản mẫu giao diện.
