# NuvoKit 0.1.2 — Windows preview

Ngày: **23/10/2026**. Dành cho **Windows 11 x64**; bộ cài chưa ký số.

- Gỡ qua Windows Settings hoặc Control Panel bằng trình gỡ native NSIS hiện có.
- Bổ sung thông điệp tiếng Việt, xác nhận thêm trước khi chọn xóa dữ liệu AppData.
- Mặc định giữ dữ liệu; silent/passive/nâng cấp luôn giữ. Không gỡ WebView2 dùng chung
  hoặc xóa file xuất bên ngoài AppData.
- Setup xác nhận trình gỡ đã được đăng ký đúng đường dẫn và phiên bản trước khi báo thành công.
- Sửa cấu hình TypeScript `noEmit` để VS Code không báo lỗi `allowImportingTsExtensions`.

Cài bản này đè lên bản cũ để cập nhật trình gỡ; dữ liệu hiện có được giữ lại.
Tải **NuvoKit_0.1.2_x64-setup.exe** trong Assets. Không cần Git/npm/Rust trên máy người dùng.

Đã qua 48 kiểm tra Setup, 6 test nghiệp vụ và 4 kịch bản NSIS trên dữ liệu giả cô lập.
Các kịch bản kiểm tra registry, gỡ chương trình, giữ/xóa dữ liệu và giữ file ngoài
vùng dữ liệu; không gỡ bản NuvoKit thật đang dùng. Chưa kiểm thử đầy đủ trên Windows
sạch, nhiều tài khoản hoặc toàn bộ thao tác qua Settings/Control Panel. RAM lõi còn
vượt mục tiêu; nhánh thiếu WebView2 và chữ ký số giữ giới hạn của bản preview trước.
