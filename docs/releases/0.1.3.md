# NuvoKit 0.1.3 — Windows preview

**23/10/2026 · Windows 11 x64 · Chưa ký số.**

- Cài đặt → **Dữ liệu & sao lưu**: export `.nuvobak`, xem trước/khôi phục, dung lượng
  theo nhóm và dọn file tạm. Giữ dữ liệu/gói hoàn chỉnh/bản phục hồi khi dọn.
- Sao lưu toàn bộ theme và lịch sử tác vụ; không kèm gói tải lại được hoặc cache.
  File không mã hóa, có kiểm tra SHA-256/format/schema và giới hạn dung lượng.
- Tạo bản phục hồi trước restore/migration; SQLite transaction bảo vệ dữ liệu nếu
  thao tác thất bại. Migration schema 1 → 2 giữ dữ liệu hiện có.
- Sửa kiểm tra hash sau cài: lấy hash đúng executable trong NSIS thay vì file
  standalone được Tauri trả về dạng trước bundle.
- Thêm kiểm chứng Windows Sandbox online/offline, upgrade từ payload phát hành
  trước và cờ kiểm tra dữ liệu dùng fixture riêng. Xem phạm vi thực tế ở liên kết dưới.

Tải **NuvoKit_0.1.3_x64-setup.exe** trong Assets và cài đè bản cũ. Máy người dùng
không cần Git/npm/Rust. Khi mở lần đầu, bản phục hồi schema cũ nằm trong `backups/`
của vùng dữ liệu app. Sau nâng cấp schema 2, ứng dụng schema 1 cũ sẽ từ chối mở
dữ liệu để tránh hạ cấp; dùng phiên bản mới để khôi phục file `.nuvobak`.

Đã qua 23 test Rust, 6 test nghiệp vụ, 48 kiểm tra Setup và 4 kịch bản NSIS fixture.
Windows Sandbox sạch không toolchain đã qua cài WebView2, nâng cấp 0.1.2, cài lại,
renderer/IPC, dữ liệu và gỡ giữ dữ liệu. Offline thiếu runtime báo lỗi đúng và giữ dữ liệu.
RAM vẫn vượt mục tiêu; nhiều máy vật lý và các nhánh lỗi nâng cao còn cần kiểm chứng.
