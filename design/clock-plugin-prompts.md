# Prompt — Plugin Đồng hồ

Ngày **23/10/2026**. Công cụ: built-in `image_gen`, skill `imagegen` và Product
Design `ideate`; model không được công cụ công bố. Ba lượt độc lập; nền không
trong suốt. Trạng thái **review**, chưa có duyệt thị giác cho bộ ảnh Đồng hồ.

Ảnh đầu vào cho cả ba: [app home light](mockups/windows-app-home-light-v01.png),
vai trò **edit target + tham chiếu phong cách**; giữ brand/khung, thay nội dung
thành plugin Đồng hồ. File đầu vào không bị sửa. Yêu cầu 1440 × 1000 px;
kích thước trả về ghi trong [danh mục](mockups/README.md#plugin-đồng-hồ--review),
không kéo giãn ảnh. Ngày neo 23/10/2026, không có lịch/ngày trong dữ liệu mẫu.

## windows-clock-focus-light-v01

Kết quả: [PNG](mockups/windows-clock-focus-light-v01.png). Prompt thực tế:

```text
Use case: ui-mockup. Edit the attached NuvoKit desktop mockup into a proposed interior screen of the CLOCK PLUGIN. The attached image is the edit target and visual style reference, not content to reproduce. Preserve the NuvoKit wordmark and geometric N mark, the compact native Windows titlebar and its window controls, front-facing complete app window, and clean established app-shell craft. Replace the home app tiles and all home content with the Clock plugin interface described below. Target canvas 1440 x 1000 px, approximately 1.44:1, no monitor or phone, no browser address bar, no desktop background or presentation board. Use exceptional production-quality UI design, careful alignment, generous 24-32px spacing, readable Vietnamese typography in Segoe UI style with accurate diacritics. Body text around 15-17px, large legible clock numerals with tabular figures, restrained consistent outline icons, 10-12px corner controls. Prefer grouping and dividers over unnecessary cards; do not put cards inside cards or add content just to fill space. The left sidebar retains 'KHÔNG GIAN CÁ NHÂN', rows 'Tổng quan', 'Thư viện plugin', 'Đã cài'; beneath 'Đã cài' add a visibly indented active child 'Đồng hồ' with a small outline clock icon and indigo/lavender selection. Then a divider and 'Môi trường', 'Cài đặt'; footer 'Dữ liệu trên thiết bị'. Main area has a small breadcrumb 'Ứng dụng / Đồng hồ', title 'Đồng hồ', and subtitle 'Tập trung theo nhịp của bạn.'. Below is a slim in-plugin mode navigation: 'Tập trung', 'Đếm ngược', 'Bấm giờ'. Keep the mode selected as specified. The primary purpose is tracking personal time with one dominant action. No charts, productivity scores, summary KPI cards, payments, account/avatar, AI chat, cloud sync, ads, fake hardware info, badges for capability certification, alarm guarantees, code, terminal or implementation details. Any task label or session history is synthetic; a timer does not prove reading progress or task completion. This is a FUTURE DESIGN, not implemented functionality. A discreet legible footer must say exactly 'Thiết kế đề xuất · Dữ liệu minh họa'. Date anchor: 23 October 2026; avoid dates/calendars. Do not cram every timer feature into this one frame. Entire application and primary controls fully in frame. LIGHT THEME using the existing NuvoKit palette: #f6f7fb canvas, #fafbfe sidebar, #ffffff surfaces, #17203a primary type, #626f84 secondary text, #e4e8f1 dividers, #6657e8 primary indigo, #efecff selected tint, restrained #21845b success status only. Avoid glossy effects, giant gradients, photorealistic images and 3D artwork.

Design direction: 'Tập trung tối giản'. Select 'Tập trung' mode. Show an IDLE Pomodoro ready to start, set to exactly '25:00'. Focus the composition on one spacious centered timer, without a surrounding oversized card. A modest label 'Sẵn sàng' appears above a very thin neutral lavender circular timer track. Within the circle show huge crisp '25:00' and smaller 'phút tập trung'. The track is neutral in this idle state, not a completed green progress ring. Above the circle a narrow optional text field labelled 'Tên phiên' with placeholder 'Bạn muốn tập trung vào việc gì?'. Below the timer show a subtle single row of duration presets '25 phút' selected, '45 phút', '60 phút'. One wide indigo primary button with a play icon and exact text 'Bắt đầu'. A small muted helper beneath 'Một khoảng thời gian cho việc quan trọng.'. Near the bottom, a quiet unboxed section 'Phiên gần đây' with two compact rows and fine separators: 'Đọc sách' / '25 phút' / 'Đã lưu'; 'Lên kế hoạch' / '20 phút' / 'Đã lưu'. These are illustrative manually named sessions, not linked records from other plugins. Keep the central timer visually dominant and the history secondary. Do not add analytics or extra panels.
```
