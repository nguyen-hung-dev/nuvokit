```text
Use case: ui-mockup. Edit the supplied NuvoKit mockup into a proposed Windows desktop main application / plugin-library screen. The supplied image is the edit target and visual reference. One complete front-facing application window only, target 1440 x 1000 px, same approximately 1.44:1 reference aspect ratio. No monitor, desk, browser frame or presentation board. Restrained emerald for status only. Crisp consistent outline icons, 12px corners, generous 24-32px spacing. Prefer grouping, whitespace and simple dividers over many bordered panels. No cards nested inside cards. Keep one clear primary action and limited supporting content. Persistent 224px left sidebar with workspace label 'KHÔNG GIAN CÁ NHÂN', navigation 'Tổng quan', 'Thư viện plugin', 'Đã cài', lower separator then 'Môi trường', 'Cài đặt'; small footer 'Dữ liệu trên thiết bị'. App is a local personal workspace with optional installable mini-apps. This is a FUTURE DESIGN CONCEPT, not a screenshot of features already shipped. All plugin names, installation state, metadata and personal work are synthetic. Do not put prices, review stars, download counters, real people, user accounts, cloud sync claims, social feed or AI upsell. Avoid dashboards with graphs, terminal commands, hardware numbers, photorealistic stock art, giant marketing hero banners, glassmorphism and extraneous controls. Do not expose OS paths or developer implementation details. Keep a discreet legible bottom caption exactly 'Thiết kế đề xuất · Dữ liệu minh họa'. Current date anchor is 23 October 2026; avoid showing dates or a calendar. Fit every section cleanly with no clipped labels or cut-off cards.

Main title 'Không gian của bạn', supporting sentence 'Mở những công cụ bạn dùng mỗi ngày.'. Main top-right indigo action '+ Thêm plugin'. Under the title a generous unboxed section header 'Ứng dụng của bạn' with compact 'Xem tất cả' text link. Display three large equal standalone application tiles in one clean row: lavender timer icon, 'Đồng hồ', subtitle 'Tập trung theo nhịp của bạn', small neutral status 'Đã cài', button 'Mở'; warm tan book icon, 'Sách', subtitle 'Tiếp tục hành trình đọc', status 'Đã cài', button 'Mở'; sage checklist icon, 'Công việc', subtitle 'Sắp xếp điều cần làm', status 'Đã cài', button 'Mở'. Below a section 'Tiếp tục gần đây' rendered as a quiet TWO-ROW LIST rather than more cards: book icon and 'Sách đang đọc' with 'Bản ghi minh họa · Trang 42'; task icon and 'Kế hoạch hôm nay' with 'Danh sách minh họa · 3 việc'. Each row has a subtle right arrow. At the bottom a calm inline discovery strip with a small puzzle icon, text 'Thêm công cụ, theo cách của bạn', secondary 'Khám phá thư viện plugin khi cần thêm tiện ích.', and text link 'Khám phá thư viện →'. Keep substantial whitespace and focus on launching installed apps; this is a plausible home view, not a feature inventory. All main content and the entire sidebar must be visible.
```
